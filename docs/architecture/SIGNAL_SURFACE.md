# 信号面

本仓库前端的视觉语言。只服务机场航班运营台，不是通用设计系统，不要搬到别的产品。

先读本文理解为什么这样画，再打开标本看它如何变位，然后才能扩到新页、新控件、旧页迁移。

| 角色 | 位置 |
|---|---|
| 理念与扩法 | 本文 |
| 视觉与 token 真值 | `frontend/signal-surface-preview.html` |
| 生产 token | `frontend/vue-app/src/styles/signal-surface.css`（只定义变量，随 `main.css` 全站注入） |
| 生产实现（待收敛） | `frontend/vue-app/`，AI 微前端 `frontend/ai-react/` |

Hex、字号、圆角、动效曲线以标本 `:root` / `[data-theme]` 为准。本文只定角色与判定，不另开一套色值。

生产里仍有 `theme-tokens.css`、`apple-theme.css`、`workspace_unified_theme.css` 等多套并存。那是债务，不是第二语言。新代码按本文与标本；改旧页时顺手映射，不要再发明第三套。

---

## 1. 背景

前端曾经同时活着几套皮肤：运营台、管理页、工作台、AI 页各说各的蓝，选中与悬停分不清，深色发脏。问题不是缺组件库，是没有一套「这台仪器怎么显形」的法。

已锁定、不要回头问的产品决定：

1. **全站一套语言。** Vue 页与 React AI 微前端同一套面、墨、声、器。AI 收编，不另起一套「智能感」。
2. **精致运营台。** 不是消费 App，也不是政务灰。密度紧凑，信息优先，chrome 退后。
3. **深色为主。** 浅色是同一套数的白天变位，不是另一套品牌。
4. **先收敛 token 与基础控件，再铺页面。** 新颜色、新圆角、新声，先改标本并过对比，再进生产。

三家规范（Apple HIG、Material 3、HarmonyOS）只用来追问第一性，不拿来做对照清单，也不允许「这一块跟 Apple、那一块跟 Material」。

## 2. 理念

### 2.1 第一性

界面是仪器。操作员在噪声里作判断；界面的职责是把事态交出去，不是表演自己。

好的一帧让人看见「现在是什么、我在哪、下一步打哪」。坏的一帧让人先看见皮肤。

### 2.2 三家各自贡献什么

融合不是折中配色。是各自只留下运营台用得上的那一条：

| 来源 | 它真正在守的 | 落到本台 |
|---|---|---|
| Apple HIG | 控件是可理解的对象；状态是对象的变位，不是换皮 | 选中是同一颗按钮的变位；离开指针，形还在，才叫状态 |
| Material 3 | 颜色是语义角色；交互、选择、校验、禁用不是同一种蓝 | 声只有四类；悬停 ≠ 选中 ≠ 主按钮 ≠ 航班延误 |
| HarmonyOS | 形随因果；动效解释发生了什么，不炫技 | 势只有入出 / 展收 / 成 / 败 / 升；打断必须真的升级 |

创造性的合：运营台要的是**有物理的透明**。有物理，是说控件摸起来像器械（有静、有按下、有持守、有禁用）。透明，是说器械自己不抢事态——面偏中性，只有行动声带色相出场。

### 2.3 道：透、法、量过

- **透。** 面是中性夜色（或白天的中性纸色）。不要让表面、描边、次墨、行动蓝全带灰蓝，否则整页发脏。行动蓝单独出场。透不是把所有器收成同一块灰：重量、触觉、常驻骨架、临时层都还在，只是不再用脏蓝和发光来冒充引导。
- **法。** 同类、同级、同形。新控件先问它属于五物里的哪一件，再问它是持守还是动词。答案决定形，不决定「再画一种」。
- **量过。** 正文与 12px 标对比 ≥ 4.5，力争 7。控件轮廓 ≥ 3.0。深色实底上坐近黑字，不坐白字。密度按 32 / 36 / 40 控件高、间距 4 / 6 / 12 / 20 / 28。改色必须在当前主题下重算，不能只看截图感觉。交感必须能被看见（位移 + 阴影），不能只改 4% 透明度。

### 2.4 五物

整套语言只有这五件。新视觉要么是其中一件的变位，要么不该存在。

**面。** 三级实色：页底 / 工作面 / 抬起面。高度靠明暗，不靠发光，不靠换圆角。对话框、弹出是抬起面；遮罩是临时的暗，不是第四级面。

**墨。** 主 / 次 / 淡 / 反。正文 MiSans。航班号、时刻、机位等标识用等宽；叙事句子里的数字用 MiSans + `tabular-nums`，不要在句中突然换成等宽。字阶：页题 20/650，标题 16/650，小节 14/550，正文 13/400，标与表头 12/550。

**声。** 一声加三态。四声：行动、安、警、危。每声三件：本声（实底）、其上（坐在实底上的字）、其衬（淡底 + 本声字）。没有第五声。进行中、已派工、VIP 都映射回这四声，不另开青绿、紫、渐变。

**器。** 控件。外壳同类；差别在变位，见 §2.5。

**势。** 四个动词：入/出（toast）、展/收（抽层或浮层）、成/败（边色或短暂反馈）、升（横幅打断）。升只能在事态升级时从「寻」和表之间插入，不许在角落闪。悬停、按下是交感的势，必须有位移，不是可有可无的装饰。

### 2.5 状态：哪些有，哪些没有

状态只有一种定义：**手离开之后，承诺还在不在。**

先前反复出错，都是因为把下面五件画成同一种蓝。

| 种类 | 是不是状态 | 形 | 例子 |
|---|---|---|---|
| 持守 | 是 | 值还在，形就还在 | 出港/进港、异常开着、深/浅、开关、勾选、当前导航、当前行、搜索框里有字、抽层开着 |
| 动词 | 否 | 点完回到静 | 导出、改派、升级、确认、取消、关闭、重试 |
| 交感 | 否 | 只在指针或焦点还在时 | 悬停、按下、获焦 |
| 事态 | 否 | 画在对象上，不画在 chrome 上 | 延误、取消、登机中 |
| 强调 | 否 | 更重，不是被按下 | 主按钮实底 |

判定一口：

1. 它记的是一个会持续的值或位置吗？是 → 持守。用 `aria-pressed` / `aria-checked` / `aria-selected` / `aria-current`，CSS 绑这些属性，不要绑一次性 class。
2. 它是一次动作吗？是 → 动词。不要 `aria-pressed`，不要点完还蓝。
3. 它只是划过或按下吗？是 → 交感。配方必须轻于持守，且不能和持守同形。
4. 它是业务对象的病情吗？是 → 事态。用胶囊或行洗底，不要做成「这行被选中」。
5. 它只是更重要吗？是 → 强调。主按钮 ≠ 选中。

持守内部也不同形，免得所有「开着」都变成同一块行动蓝。先判它是**地点**还是**谓词**，再选器。见 §2.6。

- 页签：换地点。贴内容上沿，当前项一条下划线。`aria-selected`。标本里的侧栏「版式 / 分割 / …」才是页签的亲戚。
- 分段：同一地点上、同一维度的互斥过滤（出港/进港、深/浅）。轨道里抬起一块。`role="radiogroup"`。
- 开关式按钮：同一地点上、可独立叠加的布尔过滤（异常）。关是线-强，开是行动描边 + 行动衬。`aria-pressed`。
- 导航当前位置：`aria-current="page"`，行动衬 + 行动字，无描边。
- 表当前行：行动衬 + 仅首格 3px 内条。不是每个格子一条竖线。
- 搜索有值：框内出现清除，这是值的器，不是底下再挂一枚芯片。
- 开关：滑块几何居中（`top: 50%` + `translateY(-50%)`），`::after` 必须自己 `box-sizing`。

被滤掉的行不能继续充当当前对象。没有可见选中时，详情清空，不要假装还选着看不见的航班。

### 2.6 视觉引导（透的另一面）

先前把「不要脏蓝、不要悬停冒充选中」做成了所有器一个灰。三家在这件事上其实是同一条：引导来自重量、触觉、骨架和层，不来自把所有东西涂成行动蓝。

**动词有三级，一屏一颗主。** Apple：一视图最多一到两颗 prominent，靠 style 不靠换尺寸。Material：high / medium / low，filled 是流程里的最终动作，tonal/outlined 是常用但非主，text 是可逃。Harmony：主 / 次 / 文字。落到本台：

| 级 | 形 | 何时 |
|---|---|---|
| 主 | 实底行动蓝 | 这一屏最可能做的那一个：改派、确认 |
| 次 | 行动衬 + 行动字（tonal） | 常用、但不抢主：催上客 |
| 静 | 线-强描边 | 可撤销、少用、离开：导出、取消、更多 |

主不是选中。次不是选中。静的关着开关可以长得像静，但开着必须变成持守的蓝边，不能和「导出」一直同形。

**交感必须可感知，且不得借用持守。** Apple 要求自定义按钮必有 press；悬停是 idle 的变位，不是选中。Material 的 state layer 是叠一层 on-color，选中才换容器色。Harmony 悬停要看得见，点击有缩放。落到本台：悬停是淡墨约 10%，色相仍是墨，**不要位移**（整条工具条一起跳就是丑）。按下是 `scale(0.98)`。过滤器的持守是分段滑块或开关蓝边，鼠标离开还在。两套配方不许合并。

**地点用页签，谓词用过滤。不要互借外壳。**

页签的隐喻是文件夹的耳、房间的门：人走了，底下那张纸换了一叠。结构、任务、信息架构节点变了。Apple 的 tab bar / tab view 明确写：用来导航，不拿来当动作，也不拿来切「完全同一窗里的近亲子视图」。Material 的 tabs 是同级的不同屏。Nielsen：tab 下的内容看起来「属于」这个签。

过滤的隐喻是筛子、透镜、机器上的档位：人没走，还是这张表，行被挡住或放行。列不变，任务不变，面包屑不变。

同一维度、必须单选 → **分段**（出港 | 进港）。这是一组 radio，不是两颗互不相关的 toggle。两颗独立 toggle 会允许「都开」或「都关」，那是另一套谓词。

可叠加的布尔条件 → **开关**（异常）。它不跟进出港抢维度，是在进出港这个切片上再筛一层。

只有换了地点才用页签。本台里「航班监视 / 派工 / 资源」才是页签。出港、进港、异常、搜索全是「航班监视」这一页上的 filter，必须待在寻的那一簇里，禁止拉成通栏页签，也禁止为了自圆其说去改面包屑。

**常驻是面的时间属性。** 位置条和寻/决工具条钉在滚动口外，表自己滚。常驻的是骨架，不是把过滤伪装成导航。

**临时入口用浮层，不塞进常驻栏。** Apple：菜单、popover，按钮可以长出菜单。Material：FAB / 菜单 / sheet，一屏一颗最高强调的悬浮。Harmony：气泡跟触发器，半模态跟宿主。落到本台，抬起面有三种挂法：

| 挂法 | 形 | 何时 |
|---|---|---|
| 对话框 | 居中 + 遮罩 | 暂停整页，要确认 |
| 锚浮（菜单） | 贴着「更多」 | 偶尔才用的命令，3–12 条 |
| 角浮（快捷） | 工作面右下角的悬钮 + 抬起面板 | 临时工具箱，不进常驻栏 |

悬钮用主声实底，但一页最多一颗。它不是第四声，也不是把改派再造一颗。常驻栏里已经有的主按钮不要再做进浮层。

## 3. 已经落地的法（对照标本）

打开 `frontend/signal-surface-preview.html`，以下是已经验证过的写法。扩的时候抄变位，不要抄文案段落。

### 3.1 仪器怎么铺（排版法）

好看的那一版不是碰巧。代理铺新页必须按这个顺序，不要自己发明第二套骨架。

**一页一块仪器，禁止套盒。** 页底托着整页。工作面只出现一次：整块操作台。不要「外面一张卡，里面再嵌一张卡」。标本里 `#layout` 用 `section.stage`：小节标题坐在仪器外面，操作台铺满卡片，自己不再描边、不再换圆角。工作面里再铺工作面，就是套盒，一定丑。

**仪器从上到下只有四层，少一层可以，多一层不行：**

1. **地点条。** 面包屑 + 计数。和工具条铺在同一张工作面上，不要换成页底当帽子。面包屑只报地点（工作台 / 航班监视），不报过滤。`3/4` 是当前谓词下的读出。
2. **工具条。** 寻左决右，一条，常驻，不随表滚。寻簇：搜索、互斥过滤（分段）、叠加过滤（开关）——全是谓词，排在一起。决簇：静 / 次 / 主 / 溢出（图标即可）。两簇用空隙 + 一根细线分开，不要再画框。
3. **表。** 工作面延续下去。表头不要换一层页底。行距给足（约 11px 14px），航班号略重。选中是淡衬 + 首格 2px 条。详情是旁路，用页底（低一级），不是再嵌一张工作面。
4. **升。** 只在事态升级时插在工具条和表之间。

滚动口在表（和详情）上。地点条、工具条在滚动口外面。

**控件必须齐高。** 搜索、分段、按钮、选择器都是 32。分段轨道用页底，滑块用抬起面。不要 28 和 32 混坐在同一条工具条里。

**分割。** 先空，再面，最后才线。组内 8，组间 12。同级同类禁止第二层框。声不能切版。

**不要用换脸冒充层次。** 同一件仪器里，地点条不要灰帽子、表头不要换色、过滤不要拉成通栏页签。层次靠：一次工作面、旁路降为页底、主按钮一颗、常驻不滚。

对照标本「版式」那一块抄结构。抄完如果看起来像卡中卡，就是没按这一节做。

**字与图标。** 名称用字。图标只用于已经学会的隐喻（搜索、关闭），或贴在名称旁边作第二通道（出港/进港的飞机、异常三角）。不要用图标代替生词，不要为了「更像设计」给动词再加说明小字。

**对话框。** 抬起面，右对齐 取消 / 确认。全文同一套字。标识用表格数字，不在句子中间切等宽字体。

**对比。** 标本里「深色可读性」按当前主题重算。改 token 必须过这一表。浅色一并切过去看。

生产 token 应对标本角色，而不是保留旧名再平行长一套：

| 角色 | 标本变量 | 含义 |
|---|---|---|
| 页底 / 工作面 / 抬起面 | `--face-page` `--face-work` `--face-raised` | 三级面 |
| 线 / 线-强 | `--line` `--line-strong` | 分割用弱线，控件轮廓用强线 |
| 主 / 次 / 淡 / 反墨 | `--ink` `--ink-subtle` `--ink-muted` `--ink-inverse` | 字，不是装饰 |
| 四声及其上、其衬 | `--act` `--ok` `--warn` `--danger` 与 `-on` `-soft` | 唯一的色相出口 |
| 圆角 | 6 / 8 / 10 /  pill | 格 / 控件 / 面板 / 胶囊 |
| 控件高 | 32 / 36 / 40 | 表内 / 表单 / 页级 |

深色行动蓝取标本里那支偏中性的蓝（`--act: #74b0f2`），不要回到刺眼亮蓝或灰脏蓝。浅色行动蓝是 `#0066d6`。面保持中性，让蓝只出现在声和持守上。

### 3.2 读数（数怎么摆）

数不是卡片。一个数 + 它的名 = 一个读出（`UiReadout`）；一排读出 = 读数条（`UiReadoutStrip`），坐在常驻骨架那张工作面上，靠细线分隔。

- 数用等宽（`--mono`）或表格数字，名用次墨小字，名在上数在下。数比名重一档，不再加图标。
- 声画在数上，不画在底上：`tone` 只染字（0 是常态就别染），不要给读出加彩色背景块。
- 密度两档：`dense` 给表上方那一行，`roomy` 给仪表盘首屏。同一屏不要两档混用。
- **禁止 KPI 卡。** 一排带边框、带影、带大圆角的方块＝套盒 + 第二层框，一定丑。要分组就加一根线。

**事实格（`UiFacts`）与读数分工。** 读数报**数**：大号等宽、可带声、给人扫。事实格报**值**：创建人、时刻、归属部门、绑定航班这类属性，字号同正文，不带声、不加图标——详情面上那张「属性表」就是它，一格一个名值对，缺值写「—」，不要留空、也不要写「暂无数据」占一行。

两者都不描边、不投影。要分组只加一根线；把属性排成一片小方块就又是套盒（§4.21）。已经画在别处的东西不要在事实格里再报一遍：状态与范围既然是帽下那条上的胶囊，格里就不再列。

### 3.3 会话流（话怎么摆）

一列话（`ChatMessageList`）。气泡的形只在库里定一次，各页不要再写第二套。

- 我说的靠右，行动衬（`--act-soft`）；它说的靠左，工作面 + 一根线；系统旁白居中、淡墨、无底。
- 时刻用等宽小字挂在气泡底部，不要做成头像 + 昵称 + 时间戳三件套。
- 富内容（Markdown、图、建议卡、按钮）走 `#body` 槽由页面自己渲染；气泡的形、时刻、滚到底仍归组件。组件是泛型的，页面往消息上加的字段会原样出现在槽里。
- Markdown 排版（段距、`code`、`pre`、引述、链接）也在库里定死：代码是等宽 + 一层淡墨底，引述是左边一根线 + 次墨。**不要在气泡里再嵌一张卡**——建议卡就是一根警声线起头，仅此。
- 发送器（`ChatSender`）是一件：页底 + 强线 + 获焦环整块显形，Enter 发、Shift+Enter 换行。**能中断才给「停止」**；`fetch` 没有 `AbortController` 就不要挂 `loading`，那是假的取消。
  左边的 `#tools` 槽放随手开关（@全体、附件）与字数读数（给 `maxlength` 就自动报，快满转警声），右边永远只有那一颗主谓词。
- 翻旧话：滚到顶发 `reach-start`，页面把更早的话接在头上。组件分得清「头上接了旧话」（钉住视线不跳）和「尾上来了新话」（落到底），
  但这靠首尾两个 `id` 判定——**消息的键必须稳定**。用 `Math.random()` 兜底就等于每次刷新都是新话，视线会被甩到底；
  服务端没给 id 就退到 `群:序号`，再退到「时刻|发话人|正文」，不要退到随机数。

### 3.4 图表（画布怎么对齐）

画布不继承 CSS，所以色和字族必须从 token 现算再传进去（`useChartTheme`）。图表里不存第二套色板。

- 轴线用 `--line-strong`，网格用 `--line` 虚线，刻字用 `--ink-subtle`，刻度尖收掉。
- 底透明，吃页面那张工作面；提示框是抬起面 + 一根线，不投重影。
- 状态仍是四声，且画在对象（条、点）上，不画在通道底上。此刻线是危声，是全图最高一档，别的东西不许抢。
- 主题切换后重读 token，画布与 DOM 同声。**不要在图表配置里写 hex。**

### 3.5 浮舱与坞（角上怎么浮）

临时入口从右下角浮出来：坞（`UiDock`）是常驻悬钮列，浮舱（`UiFloatPanel`）钉在坞之上。

- **浮舱不是弹窗。** 没有幕、不夺焦、不阻断底下的工作面——值班时开着，一边听一边看表。所以它只有一层抬起面 + 一根线 + 一层影。
- 四段固定：面 `face-raised` / 帽 `face-work`（与页面工作面同脸）/ 身（唯一的滚动口）/ 脚（只放主谓词）。里面不要再描第二道边、不要再换圆角。
- 身长内容自己滚（`scroll`）；身里那一列要自己滚（会话流）就把 `scroll` 关掉，身让位。
- 落点是 token：`--dock-right` / `--dock-bottom` / `--float-bottom`。**任何页面不要再自己写角浮的 `right` / `bottom`。**

**层序。** 由低到高只有五层，都在 token 里：

| 名 | token | 谁 |
|---|---|---|
| 坞 | `--z-dock` | 角上的常驻悬钮 |
| 浮舱 | `--z-float` | 钉在坞之上的旁路面板 |
| 幕 / 弹窗 | `--z-modal` | `UiModal` `UiDrawer` 和页级遮罩 |
| 菜单 | `--z-menu` | 溢出菜单、右键菜单、选择器展开 —— 压在弹窗之上，因为弹窗里也要能开菜单 |
| 吐司 | `--z-toast` | 压在最上，任何时候都要能报话 |

新面只从这五个名里挑。**不要再各自发明第 N 个 `99999`。**

### 3.6 菜单（一列谓词）

菜单（`UiMenu` + `UiMenuItem`）＝抬起面 + 一根强线 + 一层影，别的什么都不加。选择器展开的列表用同一套形。

两种落法，只此两种：

- **锚定**（溢出菜单）：外层给相对定位，菜单贴着扳机落下。
- **定点**（右键菜单）：给 `x` / `y`，自己 `fixed` 到光标处，配 `Teleport to="body"`。

项的规矩：

- 一行一个动作，常态无底色，交感时洗一层工作面色，不位移、不发光。
- `danger` 只给真会毁东西的那一项（撤销、删除），不是「重要」的意思。
- `mute` 是「看得见、点得动、但会被拒」：权限不足时留着它，让点击去把原因说出来（吐司），比灰掉不给点更好懂。真的不该点（越限、缺前置）才用 `disabled` + `title` 说明为什么。
- 图标是可选的行首标记，占位固定，缺了不会让文字跳。
- 分组就在槽里写一个 `<hr>`，只落一根线，不留大间距、不加小标题。

### 3.7 嵌板（面上降一级）

面上临时插入的一小块「降一级」区域（`UiInset`）：诊断输出、失败批次、原始报文、指标明细。

- 降到 `--face-page`（凹下去），一根 `--line` 收边。**绝不再加影、不再换圆角、不在里面套第二块嵌板**——那就是套盒。
- 有声就只动边和底（`color-mix` 兑一点声进页底），字仍是墨。
- 可关的给一颗静谓词 `×`，不要做成通栏的横幅。
- 它和升（`UiBanner`）分工：升报一句话的事态，嵌板放一小块可读的内容。一句话就别开嵌板。

---

### 3.8 弹窗（幕之上的一件事）

`UiModal`：夺焦，一次只做一件事。帽 / 身 / 脚三段，帽只放名与关，脚只放谓词，身是唯一的滚动口。

- 幕（`--scrim`）压在 `--z-modal`；菜单、吐司在它之上（见 §3.5 的层序表），所以弹窗里照样能开菜单、能报话。
- 关有三条路：帽上的 `×`、幕上点空、`Esc`。**不可轻关的**（填了一半的表、进行中的作业）才把 `closable` 关掉，然后在脚上给一颗明确的谓词。
- 身自带内衬与滚动口，所以里面**不要再描第二道边、不要再铺一层抬起面**——那就是套盒。
- 身里自己是一整套布局（两栏群聊、全宽表、自带滚动的会话流）时，给 `bleed`：身让出内衬与滚动权，内容自己撑高、自己滚。
  **不要用负 margin 去顶掉身的内衬**——那等于把弹窗的内衬数字抄进了页里，改一处要改两地。
- 弹窗与浮舱（§3.5）分工：要人停下来答的用弹窗；值班时开着一边听一边看表的用浮舱。别把浮舱做成会夺焦的弹窗。

---

### 3.9 骨架（等的时候画什么）

`UiSkeleton`：等数据的那几百毫秒，把**版**画出来，不要丢一句「加载中…」。

- **形要同构。** 几行、几栏、哪里是胶囊、哪里是头像，都对着最终布局摆。对不上的骨架比没有骨架更晃眼——数一到，版会跳。
- **只有一块砖**（线 / 块 / 胶囊 / 圆），洗光的配方只在 `UiSkeleton` 里定一次（`--sk-base` / `--sk-hi`：墨兑透明，所以深浅两色都看得见；黑兑透明在夜色面上等于没有）。各页、各 `SkeletonXxx` 不要再自带一套 shimmer。
- **砖里不写字。** 无障碍名与 `aria-busy="true"` 挂在外层那一块上，读屏报的是「这块正在取数」，不是逐块念空。
- 关了动效（`prefers-reduced-motion`）只留静底，不闪。
- 骨架是**同一块面上的等待**：不加遮罩、不开弹窗、不放转圈。
- **已经有内容再刷新时不要退回骨架**——那是闪一下重画。旧数留着，把「正在刷新」放到读数或那颗按钮上。

## 4. 注意事项

这些是已经犯过、且很容易再犯的错。扩的时候逐条当禁令，不要当风格建议。

1. **不要当通用设计系统用。** 消费产品的大圆角、玻璃、品牌渐变、AI 发光，这台仪器都不要。别的仓库不要引用本文当「公司设计规范」。
2. **悬停不是选中，但悬停必须看得见。** 悬停是淡墨约 10%，不要位移、不要行动蓝。持守是蓝衬 / 蓝边 / 分段滑块，手离开还在。`.btn:hover { background: act-soft }` 会把整页洗成「都有点选中」；位移会让整栏乱跳。两头都不要。
3. **主按钮不是选中。** 主题不要做成一颗常亮主按钮；它是深/浅分段，是持守。
4. **不要加教学小字。** 控件名称本身是文案。不要在底下再写「点这里过滤异常」。不要用筛选项芯片把异常、关键字再复述一遍——开关和搜索框自己就是状态。
5. **不要矫枉过正。** 缺状态就补持守的变位，不要补说明层、不要补第二套芯片条、不要给每个图标加 tooltip 教程。
6. **不要脏。** 面、线、次墨一旦都偏蓝灰，行动蓝再叠上去，深色会脏。先把面收成中性夜色，再让行动蓝单独出场。
7. **不要第四声。** 青绿「进行中」、紫色「AI」、渐变实底，都是噪声。
8. **不要用声切版。** 行动衬不是分区背景。
9. **选中条只打在第一格。** `box-shadow: inset` 写在每个 `td` 上会变成一排竖线。
10. **选中不能落在不可见对象上。** 过滤之后当前行没了，就清空详情。
11. **详情不是第二个选中器。** 当前对象画在行上。侧栏跟着变内容，不要再画一条「我在这里」的边。
12. **获焦环留下。** `:focus { outline: none }` 必须搭配 `:focus-visible`（2px 行动色，外扩 2px）。
13. **禁用仍要可读，但按 WCAG 可不计入对比表。** 不要用透明度把字溶进面里。
14. **React / Vue / 静态预览同一套变位。** 允许实现不同，不允许语义不同。Ant Design、组件库默认的 hover-蓝、选中洗底，盖掉。
15. **改色先改标本，再迁生产。** 生产里临时 hex 会变成第三套语言。
16. **移动端另论。** 本文管桌面运营台（紧凑、键鼠、表）。Flutter 壳不要生搬 32px 控件高；道（透/法/量过、持守/动词）可以共用，尺度另定。
17. **透不是糊成一块。** 一屏必须看得出：哪颗是主，哪条栏不滚，哪些是过滤，临时入口从哪浮出来。缺引导时补重量 / 势 / 常驻 / 浮层，不要把所有按钮涂成同一个蓝。
18. **过滤不是页签。** 同一张表上的进出港、异常、搜索都是谓词，放在寻簇里。不要为了「看起来像有层级」把过滤拉成通栏 tab，更不要让面包屑跟着过滤变。页签只给换地点。
19. **互斥过滤用分段，叠加过滤用开关。** 出港/进港不要做成两颗独立 toggle。异常不要做成分段里的第三段。
20. **临时入口不要再塞进常驻栏。** 栏里放不下就进「更多」或角上的快捷，用抬起面呈现。
21. **禁止套盒。** 工作面只铺一次。仪器不要再描一道边、换一个圆角坐在另一张工作面里。表头、地点条不要靠换脸冒充分层。
22. **不要露出系统选择器。** `appearance: none`，自制箭头；展开列表用抬起面（和菜单同一套），不要把 Windows / UA 下拉裸着扔在深色里。选择器是持守：当前值写在触发器上。
23. **展/收不要用 max-height 估一个数。** 边框和内边距放在内层，外层按内容高度过渡（`height` 从 0 接到 `scrollHeight`）。不要在加上 `.open` 的瞬间突然出现 padding / border / margin。

## 5. 如何扩大应用

读懂标本之后，按这个顺序扩。不要先画新皮肤。

### 5.1 新页

按 §3.1 铺，不要先画皮肤。

1. 写下这一页的主动线：寻、决、要不要升。只设一条。
2. 列出所有控件，按 §2.5 标成持守或动词；谓词还是地点，按 §2.6 选分段 / 开关 / 页签。
3. 一块工作面铺成仪器。地点条和工具条同面、常驻；表延续工作面；详情降为页底。检查有没有套盒。
4. 寻簇里只放过滤。面包屑不跟过滤变。
5. 控件齐高 32。对照标本「版式」抄结构，不抄航班数据。抄完如果像卡中卡，推倒重铺。

### 5.2 新控件

先问属于五物哪一件，再问持守还是动词，再在标本里找最近的亲戚抄变位：

| 你要做的 | 抄谁 |
|---|---|
| 换地点（结构/任务变了） | 侧栏那种页签 / 导航，不要抄过滤条 |
| 同一表上互斥的一维过滤 | 出港/进港分段 |
| 同一表上可叠加的布尔过滤 | 异常（`aria-pressed`） |
| 当前页的外观短模式 | 深/浅分段 |
| 这一屏最可能的动作 | 改派（主，实底） |
| 常用但非主 | 催上客（次，衬底） |
| 少用 / 离开 | 导出、取消（静，描边） |
| 偶尔才用的一串命令 | 「更多」锚浮菜单 |
| 临时工具箱 | 角上快捷悬钮 + 浮层，不进常驻栏 |
| 表里点一行 | `aria-selected` + 首格条 |
| 有字的搜索 | 框内清除，不要芯片 |
| 下拉选择 | 标本里的 `.select`（触发器像输入，列表像菜单），不要裸 `select` |
| 可展开 | 展/收：内层放边框，外层按内容高度过渡 |
| 业务病情 | 事态胶囊，映射四声 |
| 暂停整页的确认 | 对话框：取消在左，确认在右 |
| 一列按时间发生的事 | 时间线（`UiTimeline`）：点的色是事态；行里要胶囊、要点开详情就用 `#item` 槽，不要再画第二套点和第二套 tone 映射 |
| 一组「名 + 值」属性 | 事实格（`UiFacts`），不是一排小卡片 |
| 没有照片的人或部门 | 头像（`UiAvatar`）：一个字 + 一圈线，不用渐变实底 |
| 正在取数 | 骨架（§3.9），不是转圈、不是「加载中…」 |

控件的「不该点」有两种，别混：`mute` 是看得见、点得动、但会被拒（点了让吐司说原因）；`disabled` 是真的不该改（正在提交、缺前置）——`UiSelect` 的 `disabled` 是后者，字仍要可读，不要用透明度把它溶进面里（§4.13）。

找不到亲戚，说明你可能在发明第五物。停下来。

### 5.3 旧页迁移

碰哪片收哪片，不要开「全面换肤」分支却不改判定。

1. 把该页用到的旧变量（`--ws-*`、`--admin-*`、`--nl-*`）映射到标本角色，能共用就共用。
2. 删掉只为这一页存在的第四声和发光。
3. 把选中从 `:hover` / `.active` / `.is-on` 挪到 aria 属性。
4. 去掉教学小字和重复的条件芯片。
5. 深浅两套都过对比。标本里的算法可复用，不要目测。

实践中沉淀的收敛动作（工作台首页等页已验证）：

- **离档小字一律收上梯子。** 10px / 11px 的 chrome 小字归到 `--fs-label`（12/550），18px 页题归 `--fs-page`。中文里 `text-transform: uppercase` 无效，一并去掉。
- **私造件归库。** 页里自带的 shimmer 骨架、错误横幅、计数胶囊，分别换成 `UiSkeleton`、`UiBanner`、`UiPill`——洗光、声衬、胶囊形只在库里各定一次。
- **死词汇要删。** 绑在模板上、却没有任何样式表定义的 class（如 `theme-*` 色卡类）是死词汇，直接删掉，不要给它们补样式。
- **黑兑透明在夜色面上等于没有。** 悬停、衬底里的 `rgba(0,0,0,x)` 一律换成 `color-mix(in srgb, var(--ink) X%, transparent)`（悬停约 8%，衬底 4–6%）。
- **页头不铺渐变蓝。** 抽屉/面板头的 `linear-gradient(…蓝…)` 换成平面工作面 + 线分隔；选中态归 `UiButton` 的 pressed。渐变只留给数据图形，不铺 chrome。
- **库件已备，页面不许再造。** 开关归 `UiSwitch`（`v-model:checked`），下拉归 `UiSelect`，按钮三级归 `UiButton`，胶囊归 `UiPill`。扫到页内私造的同类件，直接换库件并删私样式。
- **浮层有层序 token。** 弹窗用 `--z-modal`，侧抽屉/角浮用 `--z-float`，不要再写裸的四五位数 z-index。
- **代码块刻意留深色底。** `pre`/`code` 输出块两面通用深色，不随主题翻面；chrome 小字仍按梯子走。
- **对话气泡两面分工。** 用户泡用 `--act`/`--act-on`，助手泡用墨兑透明 6% 衬底 + `--ink`，泡尾圆角用 `--r-cell`。
- **迁移期别名先查消费方再删。** 页内 `:global(:root)` 别名块与 `var(--旧, var(--更旧))` 链式回退，先全仓扫 `var(--名)` 消费方；零消费直接删，页面直接用标本名（旧色名在 variables.css 已有定义的，不由页面重定义）。
- **实底上的图标洗色要写两面。** 行动色实底芯片上的图标用 filter 洗成 `--act-on` 同色：夜色面 `brightness(0) saturate(100%)`，白天面用 `:global([data-theme='light'])` 补 `brightness(0) invert(1)`，不要只写一面。
- **终端仿色收进墨阶。** 日志/控制台的固定蓝橙（如 `#569cd6`/`#ce9178`）换成墨三阶，严重度仍走四声（tag 高/中/低归 danger/warn/ok）。
- **批量删全局 CSS 后必做深度扫描。** 只数花括号总数会被「孤儿括号」骗：选择器列表末行（带 `{`）被删后前一行尾逗号会变出孤立 `}`，浏览器静默丢弃整条规则。删后用逐行深度扫描找负深度；删列表末行时把前一行尾逗号改为 `{`。
- **帽幕关一律走库件，不许页里自卷。** 自卷 modal-overlay/modal-content/btn 三件套是各自为营的重灾区：弹窗归 `UiModal`，侧抽屉归 `UiDrawer`，页里只留表单与业务块。眉标+标题的组合走 header 插槽，分区自带内距的抽屉/弹窗用 flush 身。
- **两页贴出同一块业务，就是入库信号。** 角色弹窗与模板弹窗的权限树几乎逐行相同，抽成 `UiPermissionTree`（`v-model` 收选中键，`items` 收 `{key, description}`，组头全选/半选与寻簇都在件内），页里只做 Permission→item 的映射。
- **受控表单接库件用 computed 桥。** 父级以 `form` 对象下发、`update:form` 回收时，库件的 `v-model` 用 `computed({ get: () => props.form.x, set: (v) => update('x', v) })` 桥回，不要把库件改成事件回调风格。
- **库件自己先合规。** 迁移页面时扫到 `UiModal`/`UiDrawer` 自身还留着 14px/18px/22px 硬编码，一并归梯子（内距走 `--s3`/`--s4`，关叉字号走 `--fs-page`）。库件是规范的化身，不许带头离档。
- **状态章回语义 tone，不回类名串。** 脚本里 `xxxStatusClass()` 返回 `'badge badge-on-duty'` 这类类名串的，改成返回 `UiPill` 的 tone（`ok`/`warn`/`danger`/`act`/`mute`），业务语义在页里映射（在岗/可用 = ok，使用中 = act，维护/休息 = warn，报废 = danger，离岗 = mute）。一页一套的 `badge-XXX` 私色从此绝迹。
- **分清「全局共供」与「页内自卷」。** `admin-page.css`/`admin-layout.css` 里的 `.panel`/`.table-container`/`.empty-state`/`.search-group` 是簇内共供原语，保留类名；页面 scoped 里再写一份同义的 `.empty-state`/`.btn`/`.modal-overlay` 才是各自为营，删掉或换库件。删前全仓扫类名消费方，确认没有页外依赖。
- **纯 string 字段直连 composable ref。** `v-model="rm.teamForm.value.x"` 这类可写字段表达式可直接接 `UiSelect`/`UiSearch`，不必造桥；computed 桥只留给以 props 下发对象、`update:form` 回收的受控表单，以及联合类型收窄。
- **数组行下拉用行内事件写法。** 逐行渲染的表格里，一行一个 computed 桥不现实，改用 `:model-value="row.x ?? ''" @update:model-value="setX(row, $event)"`，setter 里回写行对象并标脏。本地 draft 的多键下拉才用泛键 `fieldBridge(key)` 助手批量造桥。
- **簇内同义标签页归全局 `.tab`。** 页里自卷的 `.inner-tab`（字号/字重/底线选中）与 `admin-layout.css` 的 `.tab` 逐条同义时，类名改 `tab` 直接用全局，页内只留布局容器与必要的负 margin 对齐；`.header-actions` 等头部原语同理，先查全局再落 scoped。
- **已库化的页只剩梯度债。** 模板件已全归库的页（如调度通知弹窗），迁移就是样式区的 padding/gap 归梯（`18px → --s4`、`12px → --s3`、`10px/8px → --s2`），结构几何尺寸（栏宽 260/300px、最小高 480px）不是梯度债，保留不动。
- **换件必同步同名测试的 DOM 断言。** 页带单测时，`badge-success` 类断言改断 `ui-pill` 的 `data-tone`，`btn-danger` 选择器改 `.ui-btn[data-variant='danger']`；断言的是语义映射（状态→tone），不是实现类名，迁完立刻跑单测兑现。
- **行内样式与裸表是离档之最，先收。** `style="padding:4px 8px"` 一路写下来的指标表，裸 `<table>` 换 `UiTable`（数字列 `data-align="end"`、标识列 `data-mono`），行内样式全收进 scoped 类名走梯度；旧 `btn btn-secondary` 同批换 `UiButton`。
- **单页迁移撞出簇内既存 lint 债，一次桥平。** 整簇 section 都在模板里直接 `v-model="form 对象 prop.键"`（撞 `vue/no-mutating-props`）时，不要逐处 eslint-disable，统一上 computed 桥（`const form = computed(() => props.modelsForm)`，模板全改 `form.`），同簇一把脚本扫平再验闸门。
- **两页同构的角浮悬钮抽成 `UiFab`。** 主声实底圆钮 + 角标徽记在两个页各写一套时，收进库：形（48px/圆/中投影/hover 位移/持守环）与徽记（18px、`data-tone` 三声、99+ 截断）都在库里；落点（fixed 定位、离边距离、页内小一号变体）归调用页 scoped 类。画布类组件（echarts/canvas）只收 DOM 壳：画内配色归两面主题对象持守，壳上的标签、分割线才走梯子。
- **三选一语义着色的 `:style` 三目改 `data-tone`。** 涨/跌/平、异常/常态这类三目内联色（`color: x > 0 ? '#22c55e' : '#ef4444'`），改 `:data-tone="cond ? 'ok' : 'danger'"` 配 scoped 三行 `[data-tone='…'] { color: var(--ok/…) }`；胶囊形的直接换 `UiPill tone`。行内 `:style` 对象是最后的高发硬编码，收完再扫一遍才算清零。
- **局部弹层的 z-index 归层序梯。** 下拉列表/浮菜单的 `z-index: 30` 这类页内魔数，改 `var(--z-menu)`；全局层序 token（`--z-dock/--z-float/--z-modal/--z-menu/--z-toast`）不只给跨页浮层用，局部弹层也用它表语义，日后调层序只改一处。
- **库件被排行扫出时优先归梯。** 库件离档是被所有调用方乘倍放大的；扫尾阶段排行榜头部若全是已完成页的持守计数，改扫 legacy 别名模式（`var(--admin-/ws-/system-…)`）与行内 `style=`，别名清零后再查库件自身，真债无处藏身。
- **迁整卷页 CSS 前先扫 e2e 选择器依赖。** 独立页的全局样式卷（如 ontology-center.css）token 化时，先 grep Playwright/cypress spec 引用的类：被断言的类名体系（`.ontology-pill.tone-ok`）保留形只换声；没被断言的私系（`oc-btn` 一族）才换库件（e2e 走 `getByRole('button')` 不依赖类名）。`margin-top` 这类行内覆盖收成语义修饰类（`stack`/`stack-sm`/`flush`/`span-2`），别发明无名的 nth-child 兄弟选择器。
- **旧双主题 token 与信号面同源，可整卷等值替。** `--ws-bg` 浅色值与 `--face-page` 同值（#edf2f8），`--ws-*` 卷可直映射到 `--face-*/--ink-*/--act`；focus 环与声边框的固定 rgba 改 `color-mix(in srgb, var(--act) 15%, transparent)` 这类兑色写法，随两面自动换声。
- **图区底座尺寸归 scoped id，不逐块内联。** echarts/条形图容器的 `style="width:100%;min-height:220px"` 收进 scoped `#chartId { width:100%; min-height:… }`；同页多块按高度分组合并写。右对齐的操作列表头（`<th style="text-align:right">`）同理收 `.col-actions` 修饰类。
- **行内图标对齐删 px 内联即可，SvgIcon 已自带 em 兑基线。** 按钮/侧栏徽标里 SvgIcon 的 `style="vertical-align:-2px"` 一律删：包裹层 `.svg-icon--inline` 自带 `vertical-align: -0.125em` 随字号自动兑。注意 scoped 规则打 `svg` 本体无效（内层 svg 不继承父组件 scope 属性），要打就打包裹层 `.svg-icon`；库件自带的对齐是全站约定，页内不要再写第二套。
- **模板里的 hex 兕底归 CSS 默认声。** `:style="{ background: x.color || '#1677ff' }"` 这类写法，把兕底色写进类规则（`.dot { background: var(--act); }`），绑定改 `x.color ?? undefined`（注意 TS：`StyleValue` 不收 `null`，可空字段必须 `?? undefined`）；有值时行内盖过默认声，无值时 CSS 接住。
- **域内状态色（非四声）走修饰类引用域变量。** 派工板图例这类引用 `--status-*` 域变量的色块，内联 `style="background: var(--status-progress)"` 收为 `.legend-color.is-progress` 修饰类；域变量本身留在域内，不升进信号面根。

Vue 与 React 都走这一条。AI 页禁止「为了智能感」加紫光、大圆角、渐变头图。

#### 5.3.3 整卷迁移五步法

碰一整卷 CSS（`workspace_unified_theme.css`、`dispatch-board.css`）时，不要边看边改色值。按这五步走，闸门始终绿：

1. **先清重复别名层。** 页内或卷首的 `--ws-*` / `--admin-*` / `--nl-*` 二次定义，先全仓扫 `var(--名)` 消费方；零消费直接删，有消费的改成 `var(--face-*)` 等标本名，不要再写一份 hex。`theme-tokens.css` 里的 `--system-*` 可以留作 fallback，但必须标 deprecated。
2. **分区梯度替换。** 最长名优先（`--ws-surface-muted` 先于 `--ws-surface`），面/墨/声/圆角/间距五组分开替。间距梯子：`--ws-space-1..5` → `--s1..s5`（8px 的 `--ws-space-2` 收成 6px 的 `--s2` 是有意的密度校正）。
3. **小步提交。** 一卷 CSS 清完立刻 `npm run build` + `npm run test`，不要攒到整仓再验。PostCSS 对「选择器列表末行被删、前一行尾逗号变孤立 `}`」不会报错，浏览器会静默丢整条规则——删后用深度扫描找负括号。
4. **闸门守护。** build 绿、单测绿、`grep --ws- <file>` 计数为 0、没有新的 `#hex` / `rgba(` 进 chrome（数据色、nl-query 专用壳除外）。
5. **采样浏览器核验。** 同一页 `data-theme=dark` / `light` 各一帧；主按钮、表头、进度条、焦点环必须两面都看得见。浅色不是另一套品牌，是同一套数的白天变位。

**案例：`dispatch-board.css` 122 → 86 → 0。** 先把 122 处硬编码色按声映射到 `--act/--ok/--warn/--danger` 和 `color-mix`，剩 86 处是字影、focus ring、rgba fallback。字影用 `color-mix(in srgb, var(--face-page) 55%, transparent)` 随面走，不必发明 `--shadow-text-highlight`；focus 脉冲用 `color-mix(in srgb, var(--act) 28%, transparent)`，不必 `--focus-ring-blue-hover`。再扫一遍，hex/rgba 归零。L233 的 overrun 条、L528 的资源焦点按钮都已经是标本名，没有非法 fallback。

**案例：`workspace_unified_theme.css` `--ws-*` 清零。** 144 行消费全部改标本名；data-hub 上那组本地 `--ws-radius-*` / `--ws-space-*` 覆盖删掉（会改写成重复的 `--r-panel: 14px; --r-panel: 18px`，后一条吃掉前一条，密度还离档）。紧凑断点只允许 `--h-md: 34px` 这种标本梯子上的局部改档。`--nl-*` 仍留给 nl-query 专用壳，不升进信号面根。

### 5.4 何时改标本

标本是语言的实验室。下列情况先改标本，看过再进生产：

- 新的持守种类（不是已有分段/开关/行选的亲戚）
- 改任何一声的色相或衬
- 改密度或圆角阶

只是把已有变位接到一个真实 API，直接改生产，不要先在标本里做假业务。

## 6. 验收

做完一页或一个控件，用这些句子自问。有一句答不上，就还没懂，不要交付。

- 手离开后，还亮着的东西，是不是都有一个仍在的值或位置？
- 这一屏能不能立刻指出那一颗主按钮？次和静是否分得开？
- 悬停能不能看出可点、会不会整栏跳？松手后会不会还蓝着（那就是错把交感当持守）？
- 是不是只有一块工作面？地点条有没有被换成灰帽子？表头有没有换色？
- 位置条、工具条会不会被表带走？
- 进出港和异常是不是还待在寻簇里当过滤？面包屑有没有被过滤改掉？
- 临时入口是从菜单或角浮出来的，还是又在栏里多塞了一颗按钮？
- 航班延误会不会被看成「这行被选中了」？
- 有没有多出来的说明小字、重复芯片、第二套选中条？
- 深色面还脏不脏？行动蓝是不是唯一的蓝？
- 12px 字和描边过没过对比？

浏览器里要点一遍持守（开、关、再开）和动词（点完应回到静）。只截一张静态图不算验收。
